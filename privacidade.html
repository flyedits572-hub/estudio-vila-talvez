Política de Privacidade

O Estúdio Vila Talvez é um aplicativo de uso pessoal. Ele acessa apenas o canal do YouTube do próprio dono, com a autorização dele, para enviar vídeos e ler estatísticas desses vídeos.

Não coletamos, vendemos nem compartilhamos dados de terceiros. Os dados de acesso ficam salvos somente no computador do dono do app. Não há outros usuários.

O app segue a Política de Dados de Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
